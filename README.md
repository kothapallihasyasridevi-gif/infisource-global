# InfiSource Corporation Private Limited

The InfiSource Corporation Private Limited website - a static multi-page site with no build step.

## Pages

| File | What it is |
|---|---|
| `index.html` | Home |
| `about.html` | About |
| `services.html` | 18 sourcing categories with the interactive explorer |
| `contact.html` | Contact details + inquiry form |
| `vendor.html` | Vendor registration |

## Assets

- `assets/css/` - the design system
- `assets/js/` - site behaviour; `config.js` holds `FORM_ENDPOINT`
- `assets/img/` - logo and favicon

## Forms

`google-apps-script.gs` is the backend for the vendor and inquiry forms (Google Sheet + Drive). See `SETUP.md`.

## Hosting

Published with GitHub Pages from the `main` branch.
